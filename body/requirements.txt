# Body-side dependencies
# Most are pre-installed on Raspberry Pi OS
#
# NOT listed here: the SunFounder SDKs `pidog` and `robot_hat` — install
# them with SunFounder's own installer (they set up GPIO/I2C system deps):
#   https://github.com/sunfounder/pidog  →  docs "Install All the Modules"
# nox-body will fail with ModuleNotFoundError without them.
#
# On Raspberry Pi OS Bookworm (PEP 668) install with:
#   pip3 install --break-system-packages -r requirements.txt
# numpy stays below 2: Bookworm's python3-picamera2 and python3-simplejpeg are
# compiled against numpy 1.x, and a pip-installed numpy 2 kills the camera with
# "numpy.dtype size changed ... Expected 96 from C header, got 88". OpenCV 4.11+
# pulls numpy 2 back in, so it is capped too.
opencv-python-headless>=4.8.0,<4.11
numpy>=1.24.0,<2
vosk>=0.3.45
piper-tts>=1.0.0
onnxruntime>=1.16       # SCRFD + ArcFace face recognition (nox_face_recognition.py)
PyYAML>=6.0             # pidog_memory.py reads/writes its store as YAML
